# Ecommerce Customer Analysis (Linear Regression)

## Problem Statement

The dataset contains information about customers who purchase clothing from an e-commerce store. Customers receive in-store styling sessions and then place orders either through the website or mobile app. The company wants to determine whether to focus more on improving its mobile app or its website.

## Objective

To predict the yearly amount spent by customers using features such as time on app, time on website, session length, and membership duration.

## Project Workflow

* Data Exploration and Cleaning
* Exploratory Data Analysis (EDA)
* Model Building (Linear Regression)
* Model Evaluation

## Key Insights

* Length of Membership has the strongest impact on customer spending
* Time on App shows a stronger relationship with spending compared to Time on Website

## Model Performance

* Mean Absolute Error (MAE): ~8.42
* Root Mean Squared Error (RMSE): ~10.19
* The model performs well with accurate predictions

## Conclusion

The company should focus more on improving the mobile app experience while also maintaining long-term customer relationships.
